# Reproduction scope

| Scope | Supplied inputs | Status |
|---|---|---|
| Fixed instrument scoring | Lean recorded component decisions, original declaration, matrix, crosswalk, standalone engine/wrapper | Runnable for all 20,604 potential pairs under each of three current specifications |
| Instrument structural checks | Full-domain benchmarks, synthetic cases, test suite | Runnable; matrix/gate/threshold/U/missing/error checks |
| Employment empirical re-scoring | Requires actual paired SOC/NAICS application inputs | Individual-level employment inputs are not retained after verification; empirical re-scoring is not available from the released aggregates |
| Profile matching, work-person reconciliation and collection dates | Original profile, selection and observation evidence | Individual-level linkage and employment evidence is not retained after verification; these procedures cannot be reconstructed from this package |

A specification range is neither a confidence interval nor calibrated bounds on individual duties.
