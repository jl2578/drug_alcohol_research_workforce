## 0.3.0-rc2 — 29 October 2026

The package supplies the revision-15 codebook, one complete scope instrument, a fixed-target research-content instrument, runtime software and reproducibility instructions for an authorized ProQuest TDM Studio Workbench.

The scope response assesses all six S1–S4 fields for every research unit and record-level S5. Substance-related and endogenous-system research use the same evidence, scope request, validation and deterministic derivation. Supported uncertainty remains explicit. Content returns C1–C9 only for the fixed qualifying targets, with the complete scope assessment protected by dependency hashes.

The notebook and package metadata identify the active codebook, prompts, schemas and runtime dependencies. Offline tests use invented records to exercise scope boundaries, uncertainty, fixed targets, invalid responses, resume, failures and one/two-worker reconciliation. The ZIP includes no source records, input datasets, identifier lists or credentials.

A fresh search-derived replication may differ from the study's records and model judgments.
